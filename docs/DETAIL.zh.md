# 对话回退

把对话就地回退到任意更早的用户消息，并可一并还原其后的工作区文件改动。全程在同一个窗口内完成：不新建分支、不切换窗口、不残留副本。

回退只向会话日志追加一条标记——原始事件仍保留在日志里，从不删除或改写。文件还原只读取插件自己的快照库：它追踪写类工具改动过的路径，并且只在内容真的变化时才保留改动前的副本。

- **目标**：任意更早的用户消息，可从消息旁的 ↶ 按钮或「回退历史」页选择。
- **范围**：仅回退对话，或回退对话并还原工作区文件。
- **撤销**：改动过文件的回退可在「回退历史」页撤销一次；仅回退对话的记录无法撤销，因为 surface 已经把那些事件折叠掉了。
